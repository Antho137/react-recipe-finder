## Features

- A simple Recipe Finder Application developed using React-vite that allows users to search for recipes and view details such as recipe ingredients
- The App contains 8 differents recipes categories
- Clicking a category will display 4 selectioned matching recipes
- Each recipe card shows a recipe image, recipe name, and show ingredients button
- Clicking the show ingredients button display recipe ingrendients, and hide ingredients button get the inverse
